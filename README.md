# Executable specifications

A worked implementation of executable specifications and acceptance
test-driven development, following Dave Farley's four-layer model: test
cases, a domain-specific language, protocol drivers and the system under
test.

This project is not about building a todo app. It is a learning platform
for executable specifications, a store of worked examples, a starting
point for new projects and a teaching resource for the team. Todo is only
the vehicle, chosen because the domain is simple.

# Quickstart

``` bash
docker compose up -d --build
```

Then visit: [http://localhost:4200/](http://localhost:4200/)
